## Sketches

We started with sketches and wireframes to figure out how the control system should actually be laid out before touching any hardware.

<MediaContainer src="/projects/smart-lighting-control-system/sketches.png" alt="Smart Lighting Control System sketches" />

## Methodology

Python handled the core logic, Flask served the web UI, and multithreading let us control multiple lights at once instead of one at a time. Jinja templates powered the front end. We tested a lot along the way since this was controlling actual physical hardware.

## Results

The system ended up managing up to 50 lights across 10 rooms with custom schedules, and held up reliably through testing.

<MediaContainer src="/projects/smart-lighting-control-system/results.png" alt="Smart Lighting Control System results" />

## Final Thoughts

This was my first real IoT project, and getting hardware and software to work together reliably taught me a lot that pure web development never really forces you to deal with - timing, physical pins, things that just behave differently than clean software abstractions.
